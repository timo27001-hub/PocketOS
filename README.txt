PocketOS v1.0 — Mini Corsa WebGL 3D. Skutočné 3D objekty a kamera cez WebGL, nie pseudo-3D canvas. Celá obrazovka PocketOS, dotykové tlačidlá s podržaním (Pointer Events), klávesnica WASD/šípky, kolo a rýchlomer. Úplne offline po prvom načítaní. Nahraj VŠETKY súbory vrátane nového sim3d.js na GitHub Pages. Web: https://timo27001-hub.github.io/PocketOS/
